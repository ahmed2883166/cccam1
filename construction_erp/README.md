# نظام المقاولات (Construction ERP)

نظام محاسبة للشركات المقاولات، بالمعايير الدولية (IFRS كما تطبقه SOCPA في السعودية)، واجهة عربية من اليمين لليسار.

**الحالة: المرحلة 0 + جزء من المرحلة 1.** موجود الآن:
- تسجيل دخول بكلمات مرور مشفّرة (PBKDF2).
- دليل حسابات افتراضي مناسب للمقاولات (مستخلصات، محتجزات، أعمال تحت التنفيذ، مقاولين من الباطن).
- قيود يومية مع منع أي قيد غير متوازن، ومنع الترحيل في فترة مقفلة، ومنع القيد على حساب تجميعي.
- ميزان المراجعة وشجرة الحسابات.
- اختبارات للقواعد المحاسبية.

**لسه ما اتعملش:** المبيعات والمشتريات والمستخلصات، المشروعات ومراكز التكلفة، القوائم المالية (المركز المالي، الدخل الشامل، التدفقات، حقوق الملكية)، الداش بورد التفصيلي، Alembic للهجرات، ربط ZATCA للفوترة.

## التشغيل بـ Docker

```bash
export CERP_SECRET_KEY="$(python -c 'import secrets;print(secrets.token_urlsafe(48))')"
docker compose up -d --build
```

ولإنشاء الشركة ودليل الحسابات والمستخدم الأولي (لازم تمرر كلمة المرور):

```bash
docker compose exec -e CERP_ADMIN_PASSWORD='كلمة-مرور-قوية' web python -m app.seed
```

افتح `http://localhost:8000`.

## التشغيل محليًا للتطوير

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
export CERP_DATABASE_URL="sqlite:///./dev.db"   # للتجربة السريعة فقط
export CERP_ADMIN_PASSWORD='كلمة-مرور-قوية'
python -m app.seed
uvicorn app.main:app --reload
```

## الاختبارات

```bash
pytest -q
```

## قواعد عامة لازم تفضل ثابتة

- كل قيد يمر على `app/accounting.py` (`post_entry`) فقط، ومحدش يكتب في جداول القيود مباشرة.
- المبالغ بـ `Decimal` ومقربة لقرشين، ومفيش `float` في أي حساب مالي.
- القيد المرحّل مش بيتعدل ولا بيتحذف؛ التصحيح بقيد عكسي.
- قبل الاستخدام الفعلي: غيّر `CERP_SECRET_KEY` وكلمة مرور المدير، وفعّل HTTPS، واختبر النسخ الاحتياطي.
